## What was built
1. **Item Designer** (`/studio/items`): item header (name in its MC colour, rarity, glint, id, base, lore, stats), plan-gated asset chips (texture: All models, sound: Saka+; links to the studios), display-context preview (the shipped In-game renderer), the When -> Only if -> Do ability graph, the 5 budget meters (the validator's `budgetOf`) and the validator's real error codes, Parameters (config path, range, old value struck through), "config.yml only, config_version 1 -> 2, N files unchanged" vs the Java files a structural edit rebuilds, the Simulator tab (the reference simulator on a sample world, timeline + log), Checks (DESIGN_CHECKS rows, compile, real client = not run), JSON view, add / remove blocks, the dock (settings-only requests via `planDesignEdit` applied in the editor, no model call; anything else: token estimate + "needs a change build").
2. **Menu + Quest designer** (`/studio/menus`, `?tab=quests`): slot grid (buttons, list slots, nav, costs, permissions), slot inspector (on-click protocol, cost / action chips, config values, permission, `economy_needs_vault`), Try it (sample player through the real CostCharger order), the owner-editable shop list (amount / price), checks per menu; quest chain, step flow (objectives with editable counts, branches, rewards), progress simulator with player events, stored-progress and active-quest meters, quest check rows.
3. **Boss + encounter designer** (`/studio/bosses`; no mockup exists, it reuses the item designer's anatomy): header (stats editable, immunities, boss bar), phase ladder on the health bar (thresholds, intervals, attack weights, phase-start actions), the selected attack (targets, range, cooldown, telegraph, per-attack budget incl. summons), arena (top-down to scale), Parameters, Fight simulator (the reference BossFight), checks; encounter waves.
4. **Motion panel** (`/studio/motion`, studio switch Texture / Sound / Model / Motion): rig tree, state machine + vars, scripted events, the browser-run motion core (preset built from its knobs, `simulate`, software `renderFrame`), transport + timeline (state band, keys where played, cue lanes, scrubbing), Knobs (preset params = the edit), Export (Minecraft caps, lowered program, what is left out), Checks; preset browser with live posters and "Use for <motion>"; phone read-only card.

Backend: `lib/cyrus/designer/studio/` (edit / analyze / sim / service / http / deps) + `/api/cyrus/designer/v1/**`; save = a NEW `edited` revision (status pending) + one design row per changed design; autosave drafts in `CyrusModelDraft` (key `designer`). Details: docs "Cyrus designer studio UI".
