# Block Studio page: PNG asset prompts for ChatGPT

How to use: paste the **STYLE** block first, then one **ASSET** line, as one message per image. Ask for a **transparent background PNG**. If ChatGPT gives a solid background, reply: "Same image, background fully transparent, no shadow."

Save each file with the name in brackets, e.g. `hero-assembling-castle.png`, and send them to me in any order.

---

## STYLE (paste this before every asset)

> Isometric three-quarter view from about 30 degrees above, of a build made entirely of Minecraft-style cube blocks: every block visible, crisp block edges, authentic Minecraft block textures (stone bricks, deepslate, oak and spruce planks, quartz, glass, copper, gold, prismarine, blackstone, cherry wood, leaves) rendered with soft realistic lighting like a high-end shader pack. Lighting: warm key light from the upper left; cool blue (#3d7bff) to violet (#8b5cff) rim light from behind on the right; warm glow from windows, lanterns and lava where they exist. Rich detail, premium game-key-art quality, sharp focus. Isolated object, fully transparent background (PNG with alpha), no ground plane, no cast shadow, no sky, no text, no logos, no UI, no people. Centered with generous empty padding on all sides. Square 1024x1024 (or the largest available).
