How to use it
  1. Drop the MP4 into your edit wherever the sponsor read goes (mid-roll works best).
  2. Tick YouTube's "Includes paid promotion" box (Details > Paid promotion).
     The small "SPONSORED" tag in the corner is extra and doesn't replace it.
  3. Say your code out loud on the end card: it holds still for the last ~3.5 s.
  4. Put the link and code in your description (text below).
  5. If you picked a language other than English, have a native speaker check
     the on-screen text before you publish.
