**Card 1 — forgot-password emails "not received":** NOT a broken flow. App sends them fine (EmailLogs: all reset sends Status=SENT; relay mail.nxeon.cloud:587 accepts; SPM-94 case-insensitive lookup already deployed; link domain https://soulpilates.com.vn correct). Root cause = **DKIM not signed**: Mailcow `get/dkim/soulpilates.com.vn` returns selector:None while DNS advertises a `dkim._domainkey` key → mail unsigned/mismatched → spam-foldered. SPF passes (include:nxeon.cloud → "v=spf1 mx ~all"), DMARC p=none. **Fix = generate DKIM in Mailcow + publish the matching record** (owner/mail side, no app change).

**Card 3 — discount not applied (200k + 400k):** feature NOT broken generally, but the **studio "Collect" flow has no discount field**. Invoices SP-INV-260814-0006 (Anastasiia 1,000,000đ) & SP-INV-260815-0007 (Vian Taracina 1,700,000đ) both have TotalDiscount=0. They were made by SchedulingService.CollectStudioPaymentAsync (Collect button) whose request DTO carries only ReferralDiscountPct and whose invoice **hardcodes TotalDiscount/LineDiscount=0m** (same in PaymentService + PackagePurchase paths). Only the manual InvoiceController path honours discounts. **Fix = add DiscountAmount to CollectBookingPaymentRequest → thread into the invoice (InvoiceService already recomputes totals) + add a Collect-modal input.** ⚠️ Both invoices are PAID IN FULL/settled → applying the discounts now = refund/credit decision for the owner; I did NOT edit them (would break paid=net).

**Card 4 — login refresh bug:** video shows /account rendering the authed shell but ALL data blank after refresh, never recovers/redirects. Root cause in `src/pages/account.astro` loadAll(): `Promise.all([me,bookings,packages])` is all-or-nothing (one sub-request reject blanks everything) + `catch{console.error}` swallows any non-401 error with no retry/redirect/UI. **Fix = Promise.allSettled, render /me independently, retry on transient, treat failed /me like 401 → /login, show inline error instead of "—".** Frontend-only.
