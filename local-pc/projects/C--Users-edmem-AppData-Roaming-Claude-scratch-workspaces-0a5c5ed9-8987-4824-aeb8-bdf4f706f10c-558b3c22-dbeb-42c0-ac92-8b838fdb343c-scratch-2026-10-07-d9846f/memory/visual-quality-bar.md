The user judges visuals harshly and wants them premium: crisp edges (no blur), saturated neon colour (not washed out), real 3D rendering (not flat 2D fakes), and the Cyrus "Y" mark high-quality and integrated into the core rather than pasted on. Backgrounds must stay subtle and natural (aurora = free-flowing curtains with rays, never ovals/blobs; parallax with the camera). Typing effects should visibly interact with the core itself.

**Why:** repeated feedback ("looks cheap", "so blurry", "washed out", "this is 2D", "they are in the shape of ovals").

**How to apply:** verify every visual change with real screenshots before reporting; iterate several rounds; offer galleries of options when taste is uncertain. See [[cyrus-windows-quirks]].
